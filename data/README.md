# Data

The competition data is **not** included in this repository (it belongs to the competition organisers).

1. Download `train.csv` and `test.csv` from the Smart MCQ Solver Challenge page on Kaggle.
2. Place them in this folder (`data/train.csv`, `data/test.csv`), or point to another folder with `MCQ_DATA_DIR`.

Expected columns: `id, prompt, A, B, C, D, E` (+ `answer` in `train.csv`).
